# Chain-of-Embedding (layer angle) (`coe`)

Family: white-box (activation geometry, label-free features). One of the trace-heads packages: every one shares the runtime in
`trace_engine/` and is trained on the same 118 cvbench cases with the same CV protocol, so
their scores compare on even ground. Generated by `solutions/trace-heads/research/export.py`.

**Pipeline:** greedy CoT with the uncertainty-profiling generator (user-only template, 2,048 prompt / 4,096 new tokens, static cache, batches of 16), then one forward pass over prompt + response for the hidden states; then the head: Chain-of-Embedding coe_ang on seg_0_5 (label-free features).

gpt-oss-120b is keyed by reasoning effort (`"default"` = medium). Fallbacks predict robust
(True): a model or effort without an entry, a failed load or batch, or a batch that would
overrun the run's time budget (`TRACE_BUDGET_S`, default 3,300 s from import).
